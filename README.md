# Data Cleaning and Visualization Project

## Overview
This project performs data cleaning, preprocessing, and visualization on a GATE cutoff dataset.

## Features
- Handle missing values
- Remove duplicates
- Detect and remove outliers
- Generate visual reports
- Analyze category-wise and year-wise cutoff trends

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Output
- Cleaned dataset
- Category comparison chart
- Yearly trend chart
- Top papers visualization
